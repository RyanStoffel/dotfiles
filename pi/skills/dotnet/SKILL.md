# .NET / C#

- Restore: `dotnet restore`
- Build: `dotnet build`
- Test: `dotnet test`
- Run: `dotnet run --project <path>`
- Format: `dotnet format`
- Add package: `dotnet add <project> package <name>`

Detect via `*.sln`, `*.slnx`, or `*.csproj`. Target the solution when one is present.
